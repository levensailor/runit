# Changelog

## 0.3.0 — 2026-11-12

- feat: rename the extension to dotrun (`levensailor.dotrun`) with Dot Run commands, setting, terminal, and log names, and move the repository to levensailor/dotrun so the project has one name everywhere.

## 0.2.0 — 2026-11-12

- feat: publish as Dot Run to the VS Code Marketplace and Open VSX from a tag-triggered publish workflow, with a new icon.
- feat: ship the `.run` agent rule automatically: Copilot chat instructions on install, a one-click `AGENTS.md` section for projects without `.run`, and a Cursor plugin carrying the same rule.

## 0.1.0 — 2026-11-12

- feat: add Run It extension that shows a status bar play button when a workspace folder has a `.run` file and runs its command in the integrated terminal, with stop, restart, multi-root picker, editor Run menu, and explorer context menu entries.
